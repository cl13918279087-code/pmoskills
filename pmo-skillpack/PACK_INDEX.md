# Project Management Pack Index

## Skills
- **project-charter-writer** — Write a concise project charter that frames purpose, scope, objectives, stakeholders, constraints, and success conditions.
- **scope-boundary-checker** — Check whether proposed work has clear boundaries, exclusions, and controllable scope edges.
- **inclusions-exclusions-writer** — Make explicit what is inside the project and what is intentionally out of scope to reduce later ambiguity.
- **constraint-assumption-register-builder** — Build a working register of constraints and assumptions that affect planning and execution.
- **wbs-builder** — Break a project into a work breakdown structure that supports sequencing, ownership, and estimation.
- **schedule-sequencer** — Sequence work packages and dependencies into an executable delivery order.
- **milestone-planner** — Define decision, delivery, review, and release milestones with meaningful criteria.
- **risk-register-builder** — Create a project risk register with causes, impacts, likelihood, responses, and owners.
- **cost-estimation-helper** — Help estimate project costs using rough-order, bottom-up, or assumption-aware methods.
- **earned-value-tracker** — Track cost and schedule performance using simple earned value indicators and explain what they mean.
- **etc-reestimation-helper** — Re-estimate expected remaining cost and schedule exposure when the current plan is slipping.
- **stakeholder-comms-planner** — Plan who needs what communication, when, why, and in what format across the project lifecycle.
- **closure-report-writer** — Write a project closure report covering outcomes, open issues, handover status, and completion evidence.
- **lessons-learned-summarizer** — Summarize lessons learned into reusable, evidence-backed improvement statements.
- **ethics-management-plan-writer** — Write a practical ethics and governance plan for project decisions, conduct, and stakeholder treatment.
