config-item-management

## Purpose

配置项管理（Configuration Item Management）是项目管理的基础支撑活动，通过建立配置项登记册、版本控制、基线管理和变更跟踪，确保项目过程中产生的各类资产（文档、代码、模型、数据等）具有完整的可追溯性。

**本技能适用于：**
- IT系统开发项目
- 基础设施建设项目
- 产品研发项目
- 任何需要严格版本控制和变更追踪的项目

## When to use
## When to use this skill

- 项目启动时需要建立配置管理机制
- 需要跟踪项目交付物的版本和变更
- 需要定义和管理项目基线
- 需要建立变更影响的追溯能力
- 项目进入验收或审计阶段

## Procedure

> This skill follows the **基线变更流程** (Baseline Change Process) defined above. Execute: 变更申请 → CI影响分析 → 变更审批 → 实施变更 → 验证发布.

```
申请基线变更
    ↓
评估变更影响
    ↓
变更审批
    ↓
创建新基线
    ↓
原基线归档
```

## Version Control Rules

### Version Numbering Convention

| 场景 | 版本格式 | 示例 |
|------|----------|------|
| 初始版本 | V1.0 | V1.0 |
| 小幅修订 | V1.0 → V1.1 | V1.1 |
| 中等变更 | V1.1 → V1.2 或 V2.0 | V2.0 |
| 重大变更 | V2.0 → V3.0 | V3.0 |
| 修复版本 | V2.0 → V2.0.1 | V2.0.1 |

### Version State Machine

```
     ┌─────────────────────────────────────┐
     │                                     │
     ▼                                     │
[草稿] ──审批通过──→ [已批准] ──基线锁定──→ [已锁定]
     │                    │                  │
     │                    │                  │
     └──撤回──→ [已废弃]  └──新版本发布──┘
```

| 状态 | 说明 | 可否修改 |
|------|------|----------|
| 草稿（Draft）| 正在创建或修改中 | 是 |
| 已批准（Approved）| 已通过审批 | 需要走变更流程 |
| 已锁定（Locked）| 已纳入基线 | 不可直接修改 |
| 已废弃（Obsolete）| 已废弃 | 否 |

## CI Change Process

### Change Workflow

```
CI创建/修改请求
    ↓
配置管理员初审
    ↓
技术评审（如需要）
    ↓
变更审批
    ↓
执行变更
    ↓
验证与关闭
    ↓
更新CIR
```

### Change Impact Assessment

| 影响级别 | 影响范围 | 审批层级 |
|----------|----------|----------|
| 低 | 仅影响单一CI | 配置管理员 |
| 中 | 影响多个相关CI | 项目经理 |
| 高 | 影响基线或核心架构 | 技术委员会/变更委员会 |

## Best Practices

### Do's ✅

- 项目启动时即建立CIR
- 为每个CI指定唯一编号和明确负责人
- 建立清晰的版本命名规则
- 重要CI纳入基线管理
- 定期生成配置状态报告
- 保持CIR与实际状态同步

### Don'ts ❌

- 不要遗漏未入库的配置项
- 不要跳过变更审批流程
- 不要在基线锁定后直接修改CI
- 不要让多个版本同时生效
- 不要忽视CI之间的关联关系

## Failure Modes to Avoid

| 失败模式 | 说明 | 应对 |
|----------|------|------|
| ❌ CI遗漏 | 重要资产未登记 | 建立入库检查清单 |
| ❌ 版本混乱 | 多版本共存导致混乱 | 严格执行版本回收 |
| ❌ 基线破坏 | 基线被意外修改 | 权限控制和定期审计 |
| ❌ 追溯缺失 | 变更无法追溯 | 完整记录变更历史 |
| ❌ 职责不清 | CI无人负责 | 明确责任人并公示 |
