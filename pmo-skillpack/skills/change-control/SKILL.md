change-control

## Purpose

变更控制是项目管理最重要的防御机制之一。在项目执行过程中，变更不可避免，但未经控制的变更会导致范围蔓延、进度延误和成本超支。本技能指导如何建立有效的变更控制流程，确保每个变更都经过适当的评估、审批和实施。

**本技能适用于：**
- 所有项目类型的变更管理
- IT系统开发和实施项目
- 基础设施建设项目
- 产品研发项目

## When to use
## When to use this skill

- 项目启动时需要建立变更控制机制
- 收到变更请求（内部或外部）
- 需要评估变更的影响
- 需要召开变更控制委员会（CCB）会议
- 项目范围、进度或成本需要调整

## Change Control Framework

### The 5-Stage Change Process

```
Stage 1: 变更受理
    ↓
Stage 2: 影响评估
    ↓
Stage 3: 变更审批
    ↓
Stage 4: 变更实施
    ↓
Stage 5: 变更验证与关闭
```

## Change Categories

### By Impact Level

| 类别 | 影响范围 | 审批层级 | 示例 |
|------|----------|----------|------|
| 紧急变更 | 影响生产环境，需立即处理 | 项目经理 + 相关干系人 | 生产故障修复、安全漏洞修补 |
| 标准变更 | 正常范围内的变更，有既定流程 | 项目经理 | 常规功能调整、文档更新 |
| 重大变更 | 影响项目基线，需CCB审批 | 变更控制委员会 | 范围重大调整、架构变更 |

### By Change Type

| 类型代码 | 类型名称 | 说明 |
|----------|----------|------|
| CR-SCOPE | 范围变更 | 增加/减少/修改项目范围 |
| CR-SCHE | 进度变更 | 调整里程碑或交付日期 |
| CR-COST | 成本变更 | 预算调整或资源增加 |
| CR-RESR | 资源变更 | 团队人员或外部资源变化 |
| CR-TECH | 技术变更 | 技术方案、架构或工具变化 |
| CR-QUAL | 质量变更 | 质量标准或验收标准变化 |
| CR-RISK | 风险相关变更 | 因风险应对导致的变更 |

## Impact Assessment Criteria

### Impact Level Definitions

| 影响维度 | 低影响 | 中影响 | 高影响 |
|----------|--------|--------|--------|
| **范围** | 单个功能点内的调整 | 涉及多个功能点 | 影响核心功能或架构 |
| **进度** | 不影响里程碑 | 里程碑延期≤1周 | 里程碑延期>1周 |
| **成本** | 变化<5% | 变化5%-15% | 变化>15% |
| **资源** | 不需要新增资源 | 需要短期资源 | 需要长期资源 |
| **质量** | 无影响 | 需要额外测试 | 可能影响质量标准 |
| **风险** | 风险等级不变 | 风险等级提高一级 | 引入新重大风险 |

### Scoring Matrix

```
影响得分 = 范围得分 + 进度得分 + 成本得分 + 资源得分 + 质量得分 + 风险得分

评分标准：
- 低影响 = 1分
- 中影响 = 2分  
- 高影响 = 3分

总得分：
- 6-10分：低影响变更
- 11-15分：中影响变更
- 16-18分：高影响变更
```

## Best Practices

### Do's ✅

- 所有变更都应记录在案，即使被拒绝
- 影响分析应基于数据而非直觉
- 紧急变更事后应补办审批手续
- 定期回顾变更模式，识别深层问题
- 变更批准后及时更新项目计划
- 保持变更日志的完整和可追溯

### Don'ts ❌

- 不要口头同意变更，必须书面审批
- 不要跳过影响评估直接讨论方案
- 不要让紧急变更成为常态
- 不要忽视变更对文档的影响
- 不要在未批准前开始实施
- 不要让变更控制流于形式

## Failure Modes to Avoid

| 失败模式 | 说明 | 应对 |
|----------|------|------|
| ❌ 口头变更 | 变更未书面记录导致追溯困难 | 严格要求书面申请 |
| ❌ 范围蔓延 | 变更累积导致项目失控 | 控制变更总量 |
| ❌ 审批流于形式 | 审批人未认真评估 | 提供清晰的评估标准 |
| ❌ 紧急变更滥用 | 频繁紧急变更破坏项目节奏 | 事后补办正式审批 |
| ❌ 文档不同步 | 变更实施但文档未更新 | 将文档更新纳入变更验收 |
| ❌ 变更日志缺失 | 无法追溯历史变更 | 指定专人维护变更日志 |
